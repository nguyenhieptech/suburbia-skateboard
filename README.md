# Suburbia Skateboard

An animated 3D landing page for a skateboard brand featuring an interactive 3D visual customizer.

## Tech stack

- NextJS
- TailwindCSS with fluid-tailwindcss
- React Three Fiber (Three.js)
- GSAP
- pnpm

## Development

```bash
cd web
pnpm i
pnpm dev
```
